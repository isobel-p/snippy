# Snippy
![The 3D view for Snippy.](https://cdn.hackclub.com/01a0458e-16d1-739c-a0fc-449b0d0d2d47/Screenshot%202026-08-28%20002847.png)

Snippy is a USB dongle for taking screenshots, in a compact form factor. Often in class I have to take a bunch of screenshots of the teacher's presentations so I can make notes on them later. But doing that 10 times a day is boring. Why not make it fun with clicky tactile buttons? (Everything is better with clicky buttons.) The PCB is only 12x50mm!

## Features 
- Small size
- OS agnostic
- Fun to press
